\# 🎯 Análisis de Loterías Colombia



Aplicación web para análisis de loterías colombianas con IA.



\## Características



\- 16 Loterías Colombianas

\- Predicciones con Machine Learning

\- 5 años de datos históricos

\- Signos zodiacales para Astro Luna y Astro Sol



\## Uso Local



pip install -r requirements.txt

python app.py



Visita http://localhost:5000
